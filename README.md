# Command Input

**Command Input** is a puzzle game where you control a character navigating through a corporate environment, using a drawing tablet to input commands by drawing shapes. Developed as my final project in the second year at Champlain College, this game emphasizes unique input mechanics and engaging puzzle design.

## Features
- **Drawing Tablet Integration**: Utilize a drawing tablet to draw shapes corresponding to commands.
- **Puzzle Mechanics**: Solve puzzles by interacting with various elements like boxes, buttons, and doors.
- **Battery System**: Manage limited moves per level, adding strategic depth.
- **Email-Based Tutorials**: Receive in-game emails that serve as tutorials and enhance the narrative.
- **Unique Login System**: Start the game by entering a username and password, with the username used in subsequent emails.

## Development Highlights
- **Puzzle Design**: Implemented mechanics such as box-pushing, battery management, and interactive doors to create challenging puzzles.
- **UI Tools Programming**: Developed an email system using Unity's scriptable objects to deliver tutorials and narrative content.
- **Iterative Development**: Engaged in multiple QA testing sessions, refining the game based on feedback.
- **Documentation**: Authored a comprehensive technical planning document detailing systems, mechanics, and design processes.
